# AI 创新部项目管理平台

项目管理平台产品展示页，包含首页、项目动态、预览大屏、风险预警与每日简报。

## 当前交付内容

- `site/`：已构建的静态页面、脚本、样式、图片、视频及旧版页面入口。
- `部署说明.md`：交付说明与 Nginx 配置示例。
- 当前目录没有源码工程、`package.json` 或后端服务，不能在这里执行 `npm run build` 重新构建。
- `site/` 是静态交付包，已按用户要求作为例外纳入仓库。克隆后即可启动静态预览；`.vite/` 等运行缓存不提交。

## 本地预览

需要 Node.js 和 npm。在 PowerShell 中运行：

```powershell
Set-Location 'D:\Codex_projects\My_Github_Projects\frontend\apps\AI-projetcs-management-platform'
npx.cmd serve -s site -l tcp://127.0.0.1:3001
```

首次运行时，npx 可能提示安装 `serve`。启动后访问 http://127.0.0.1:3001/；按 `Ctrl+C` 停止服务。若端口已被本项目的预览服务占用，直接访问现有服务，或先停止它再重新启动。

静态服务器需要将前端路由回退到 `index.html`，以支持 `/login` 等地址直接访问与刷新。`serve -s` 提供该回退能力。当前交付包按站点根路径 `/` 构建，不应直接双击 HTML 或挂载到未经调整的二级路径。

## 后端依赖

首页、产品展示及本地动效可以独立预览。飞书登录、真实项目数据、通知、预警和每日简报需要配套后端 `/api/` 服务。

仅启动静态前端时，页面会提示本机服务未连接；接口请求可能因收到 HTML 而出现 JSON 解析错误。这不表示静态页面未启动，也不代表登录或真实业务功能可用。

## 正式部署

将 `site/` 作为 Web 站点根目录，配置前端路由回退，并将 `/api/` 反向代理至实际后端。参考[部署说明](部署说明.md)中的 Nginx 示例；示例后端地址为 `http://127.0.0.1:8001`，需按部署环境调整。

当前完成的是本机静态预览，未部署公网服务或配套后端。
