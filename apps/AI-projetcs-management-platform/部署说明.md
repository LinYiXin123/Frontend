# AI创新部项目管理平台产品页前端交付包

## 交付内容

- `site/`：生产构建后的前端静态文件，可直接放到 Nginx、Apache、对象存储静态站点或内网 Web 服务中。
- 已包含首页五段产品展示与交互动效：首页、项目动态、预览大屏、风险预警、每日简报。
- 已包含产品工作台页面所需的脚本、样式、图片、视频资源和旧版页面入口。

## 部署方式

把 `site/` 目录作为站点根目录发布即可。示例 Nginx 配置：

```nginx
server {
  listen 80;
  server_name your-domain.example;
  root /opt/ai-project-hub-frontend/site;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }

  location /api/ {
    proxy_pass http://127.0.0.1:8001/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

## 注意事项

- 首页产品页和动效资源是静态前端内容，部署 `site/` 后即可呈现。
- 登录后的项目工作台需要后端 `/api` 服务提供真实项目、通知、预警、飞书登录等数据；如需和本机效果一模一样，请同时部署当前项目后端，并保持 `/api` 反向代理可用。
- 如果客户部署到二级路径，请同步调整前端资源路径或使用根路径代理；当前包按站点根路径 `/` 构建。
