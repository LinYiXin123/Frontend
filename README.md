# Frontend

用于集中管理多个独立产品页与前端应用。

## 协作与提交约定

- 提交类型和说明统一使用中文，例如“新增：增加项目预览入口”“修复：解决首页卡片遮挡”“文档：补充本地启动说明”。
- 用用户看得懂的语言说明改了什么、体验有什么变化、验证结果如何。
- 完成优化、修复或相关文档维护并验证后，自动提交并推送到本仓库，完成后提供提交链接。
- 只提交当前任务相关内容，不混入其他会话的未完成改动。完整规则见 [AGENTS.md](AGENTS.md)。

## 目录约定

- `apps/<project-name>/`：每个产品页或应用使用独立目录。
- 每个应用自行维护依赖、构建配置、测试和说明文档。
- 依赖、构建产物、本地缓存和真实环境变量不提交到仓库。
- 静态交付包例外：按用户要求，仅 `apps/AI-projetcs-management-platform/site/` 纳入版本管理；其中的运行缓存仍不提交。
